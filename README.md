# Feasible Is Not Faithful: project page

Plain HTML, CSS and JS, no build step. Open `index.html` directly, or serve the folder with `python3 -m http.server`.

- Measured numbers: `assets/data/manifest.json` (and `manifest.js`, the same content, so that the page also works from `file://`). Generated by `project_site/prep/build_manifest_u41m.py` in the paper repository from the hardware run logs. Do not edit by hand.
- Videos: cut and compressed from the recordings by `project_site/film/cut_u41m.py` (clip list: `project_site/prep/clips_u41m.json`). No sound, no metadata; cropped and sped up as stated on the page.
- `assets/media/mechanism.mp4` is a rendering (`project_site/render/`), not a recording.
- Replacing a video: put `<name>.mp4` and `<name>.jpg` in `assets/media` through the clip list and rebuild the manifest. The post runs use the names `post_uf` and `post_uy`; the "coming soon" card goes away once both exist.
- Font: Inter (SIL Open Font License), Latin subset, in `assets/fonts`.
