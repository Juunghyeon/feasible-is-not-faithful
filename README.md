# Feasible Is Not Faithful: project page

- Static site: open `index.html` through any web server, e.g. `python3 -m http.server`.
- `assets/data/manifest.json` holds every number the page shows. It is generated by
  `ipcr-paper/project_site/prep/build_manifest.py` from the result files; do not edit it by hand.
- Films and stills come from `ipcr-paper/project_site/film` (rendered from logged runs).
- Sections:
  - Hero: a two-row "nearest point vs ours" strip.
  - TL;DR, Abstract.
  - Video: the main film and two short films.
  - Problem: an interactive target-level widget.
  - Method: A / B / C.
  - Results:
    - (A) pen gallery: shape × board, from the manifest;
    - (B) absorption, real robot;
    - (C) box gallery, pending;
    - (D) prediction chart.
  - Hardware, Limitations, Citation.
- Pending items are drawn as hatched placeholders, and the box cells say "pending" until the final runs.

## Layout ideas taken from other project pages (2026-11-21)

- **CLEAR:**
  - a fixed table of contents on wide screens;
  - a scene loop first, then the title card;
  - soft highlights tied to concepts (orange = nearest point, blue = target level, green = execution level);
  - "Inspect in 3D".
- **Transformer Transformer:** big numbers under the TL;DR; question-style headings.
- **Hold Before You Step:** two-row "baseline vs ours" strip; films rendered from logs (viser + Chromium + ffmpeg).
- **"Inspect in 3D"** (`assets/js/viewer3d.js`, three.js 0.160):
  - replays an exported scene (`assets/data/scenes/*.json`, from `project_site/prep/export_scene.py`);
  - every pose is a logged joint configuration.
