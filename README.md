# Feasible Is Not Faithful: project page

Plain HTML, CSS and JS; open `index.html` directly, or serve the folder with `python3 -m http.server`. `index.html` is written by `project_site/page/build_page.py` in the paper repository (template plus citations and references read from the manuscript): edit the template, not this file.

- Measured numbers: `assets/data/manifest.json` (and `manifest.js`, the same content, so that the page also works from `file://`). Generated by `project_site/prep/build_manifest_u41m.py` in the paper repository from the hardware run logs. Do not edit by hand.
- Measured numbers also include the registered simulation verdicts (`sim` in the manifest: `experiments/sim2real_unified/u41m_confirmatory.json`, `hyb_confirmatory.json`, `fpro_confirmatory.json`).
- Videos: cut and compressed from the recordings by `project_site/film/cut_u41m.py` (clip list: `project_site/prep/clips_u41m.json`). No sound, no metadata; cropped, sped up as stated on the page, and one mild global colour grade (`GRADE` in the script) for every clip.
- `assets/img/overview.webp|png`: Fig. 1 of the paper (`figures/scripts/fig01_overview.py`).
- Colours follow the paper: IPCR vermilion (the red pen), nearest point black (the black pen), U-yaw dark red.
- `assets/media/mechanism.mp4` is a rendering (`project_site/render/`), not a recording.
- Replacing a video: put `<name>.mp4` and `<name>.jpg` in `assets/media` through the clip list and rebuild the manifest. The post runs use the names `post_uf` and `post_uy`; the "coming soon" card goes away once both exist.
- Font: Inter (SIL Open Font License), Latin subset, in `assets/fonts`.
